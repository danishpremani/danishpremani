# Hi, I'm Danish

I build small products that turn a stressful decision into one clear answer. They live under **[GreenLabs](https://green-labs-eight.vercel.app)**, my software lab.

## What I've built

| Product | What it does | Built with |
| --- | --- | --- |
| **[Clearpick](https://clearpick-three.vercel.app)** | Compares 130 credit cards, bank accounts and CDs side by side, with calculators that show what each is worth on your own spending. Every figure shows when it was last checked against the issuer. | JavaScript, Node.js, GitHub Actions |
| **[Keystone](https://keystone-investment-calculator.vercel.app)** | Answers money questions one step at a time: a few questions in, a personal plan out, with your options for decisions like a 401(k), debt, taxes, RSUs or ESPP shown side by side. | React, Vite, Recharts, Supabase |
| **[Convoy](https://convoy-pearl.vercel.app)** | One link where a group settles the dates, destination and budget for a trip, with no accounts needed. | Next.js, Supabase, Tailwind CSS |
| **[Pulse](https://hobby-finder-steel.vercel.app)** | Host and join in-person fitness and wellness events, starting in Austin. | Next.js, Supabase, Mapbox |

Each one is live. The source is private for now; I'm happy to walk through any of it.
